The company catalogue

No applicant tracking system publishes a directory. Greenhouse has thousands of customers and no way to list them — /v1/boards and /v1/jobs both return 404, while /v1/boards/stripe/jobs returns 200. There is no sitemap either. The only way in is a slug you already know, so the reachable set is bounded by what can be named.

Every entry below was probed against the live API before being written down. Of 298 candidates tried across three passes, 113 answered with real jobs; the rest were dropped rather than shipped hopefully, because a slug that silently yields nothing costs a request on every refresh.

These are a floor, not a ceiling. Discovery reads slugs off real careers pages and writes what it verifies into a catalogue shared by every board. Finding a slug costs a few web searches once; the slug is then permanent and identical for everyone, so the next board in that field gets it for nothing. Thin fields no longer wait for somebody to want them: a background pass on the cron tops up whichever field is furthest below fifteen boards, one per tick, and stops entirely once every field is at target. Discovery is off the critical path of board creation for good.

Where the API key is spent

Four call sites, nothing else. Every one is gated by the same daily allowance, and the allowance is claimed before the request goes out — so a crash mid-call costs the budget rather than escaping it.

Ranking jobs

~1 call per refresh

Reads your sentence and scores each posting against it. Jobs the built-in scorer already rates below 35 are never sent — paying to confirm a warehouse role isn't a photography job is the easiest waste to cut.

Scouting the web

~5–15¢ per run

The costly one: every search is billed on top of tokens. Finds organisations to approach directly, for work no job board carries.

Reading your CV

1 call, on upload

Pulls out skills, titles and years. Works without a key too, just less well — the built-in reader handles the common case.

Finding employers

1 call per board, weekly

Decides which companies are worth watching for your criteria, and verifies each has a live job board before connecting it.

Nothing breaks without the key. Every path falls back to the built-in scorer, which is why a missing key was invisible for so long — the board kept working, just worse. That is also why the daily ceiling is enforced rather than advised: an overspend would have no symptom until the bill.
